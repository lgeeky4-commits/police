# Border Control — Theme Studio v1.2

This is part of the **fictional Border Control roleplay game**, not an operational system.

## Use
1. Open the Border Control website and join a room.
2. Press **THEMES / EDIT** in the top bar.
3. Choose **IMAGE FILTERS** for Grit, Grit Size, Hue, Contrast, Saturation, Brightness.
4. Choose **UI EDITOR** to edit an individual box (header, operations, map panel, communications, chat box, buttons, popups), letter color, line color, font and interface pattern.
5. Choose **30 WALLPAPERS** to pick from 30 included SVG backgrounds.
6. Enter a name and press **SAVE THEME**. Up to eight local presets can be saved.
7. Load a preset with the saved-name buttons. These settings are stored on that specific browser/device, and do not automatically change other players' themes.

Images in `public/wallpapers/` are built-in SVG wallpapers. No extra files need uploading.

## Notes
- Camera/photo/video and walkie-talkie from v1.1 remain available. They require an HTTPS connection and permissions on normal phones.
- Wallpapers, themes and patterns are cosmetic only.
